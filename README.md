# Sri Sai Institute of Technology and Science (SSITS)
## Faculty Attendance, Student Management & WhatsApp Automation System

Official institutional attendance and student management portal for **Sri Sai Institute of Technology and Science**, supporting both **Diploma (Polytechnic - 3 Years)** and **B.Tech (Degree - 4 Years)** with **Super Administrator Master Control**, automated parent WhatsApp notifications, HOD summary alerts, and vibrant modern UI.

---

### 👑 Super Administrator Master Control:

If a faculty member forgets their username or password, or if college management needs to edit student information, the **Super Administrator** has full master override access:

- **Admin Login URL:** `http://127.0.0.1:5000/login` (Switch to the *"Administrator Login"* tab)
- **Admin Username:** `admin`
- **Admin Password:** `admin123`

#### Administrator Capabilities:
1. **Reset Any Faculty Password:** Select any teacher from the 27 classes and set a new password with 1 click!
2. **Edit Faculty Information:** Update faculty names, mobile numbers, and usernames.
3. **Master Student Roster & Data Editor:** Search across the entire college database, edit student roll numbers, names, father names, and parent WhatsApp phone numbers.
4. **HOD Contact Manager:** Update Department Head contact numbers that receive daily WhatsApp summaries.

### 🎨 Vibrant & Colorful Modern User Interface:
- **Dynamic Gradient Stat Cards:**
  - 🟣 **Total Enrolled:** Electric Purple Gradient (`#4A00E0` → `#8E2DE2`)
  - 🟢 **Present Count:** Mint Emerald Gradient (`#11998e` → `#38ef7d`)
  - 🔴 **Absent Count:** Sunset Crimson Gradient (`#eb3349` → `#ff5858`)
  - 🟡 **Attendance Rate:** Radiant Gold-Amber Gradient (`#f7971e` → `#ffd200`)
- **Interactive Role Switcher:** Toggle smoothly between *Faculty Login* and *Administrator Login*.
- **Department Color Badges:** Distinct vibrant color identities for ECE, CSE, AI&DS, EEE, MECH, and CIVIL.
